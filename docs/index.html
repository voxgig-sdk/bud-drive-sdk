Overview

Drive API

Drive lets you understand your customers using the flags it compiles from data across every source you bring in, not just transactions, build segments from those flags, and run personalised campaigns against them. Drive works in a loop: understand your customers (via the flags that make up Drive's criteria), segment them (Drive Segments API), and engage them (Drive Campaigns API). Measuring a campaign's performance feeds back into segmentation, so the next audience is sharper than the last. Campaigns don't have to be built step by step, either: describe the outcome you want in plain language and Drive's campaign agent finds the matching audience, writes the copy, generates the artwork, and estimates the opportunity for you. Segments V2 endpoints return non-standard vendor content types (application/vnd.bud.drive.notification+json, .criteria+json, .visualisation+json, .criteria-options+json) rather than plain application/json, check the Content-Type of these responses rather than assuming JSON.
